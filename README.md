# 從洞察到證據：產品實驗與快速原型

東海大學產品開發進階課程的互動式網頁簡報。

## 線上瀏覽

https://gm0621.github.io/thu-product-evidence-courseware/

## 課程內容

- 前次課程的五項共同前提與流程回顧
- 找出最危險的產品假設
- 把想法寫成可被推翻的假設
- Concierge MVP、Wizard of Oz 與 Fake Door
- 非誘導式使用者訪談
- 預先設定成功門檻
- 根據證據決定繼續、調整或停止

## 操作方式

- `←`／`→` 或 `PageUp`／`PageDown`：切換投影片
- `Space`：下一頁
- 「總覽」：快速跳頁
- 「全螢幕」：進入投影模式
- 「列印」：輸出完整講義或 PDF

簡報為自包含靜態 HTML，不需要後端服務。
